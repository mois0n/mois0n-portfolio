Instalación de Proxmox VE como base de laboratorio

Proxmox VE fue la base utilizada para construir un entorno de laboratorio donde desplegar máquinas virtuales, contenedores, servicios web, base de datos y firewall.

Proxmox VE Virtualización Linux Infraestructura IT

Objetivo

El objetivo de usar Proxmox VE fue disponer de una plataforma de virtualización centralizada para crear y gestionar los distintos componentes del proyecto.

Por qué Proxmox VE

Proxmox VE permite crear máquinas virtuales y contenedores, gestionar redes virtuales, almacenamiento y recursos desde una interfaz web. Esto lo convierte en una buena base para laboratorios de sistemas, redes y seguridad.

Rol dentro del proyecto

Servidor físico
   └── Proxmox VE
        ├── IPFire
        ├── Servidor web
        ├── Base de datos
        ├── phpMyAdmin
        └── Contenedor de automatización

Qué demuestra esta parte

  • Instalación y uso de una plataforma de virtualización.
  • Organización de servicios por máquinas o contenedores.
  • Gestión de recursos básicos.
  • Diseño de redes virtuales.
  • Base para desplegar una infraestructura segura.

Buenas prácticas

  • Separar servicios críticos.
  • Nombrar máquinas de forma clara.
  • Documentar redes y funciones.
  • Realizar copias o snapshots antes de cambios importantes.
  • No exponer la administración sin protección.

Conclusión

Proxmox VE permitió construir una infraestructura flexible y ordenada, facilitando el despliegue de servicios y la segmentación del entorno de laboratorio.
