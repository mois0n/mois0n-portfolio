Servicios web · Linux · Base de datos

Despliegue de Apache, MySQL y phpMyAdmin

Esta entrada documenta el despliegue de servicios web y base de datos dentro de una infraestructura virtualizada orientada a laboratorio profesional.

Apache PHP MySQL phpMyAdmin Linux

Objetivo

El objetivo fue desplegar una base funcional para una aplicación web, separando los servicios necesarios y documentando su papel dentro de la infraestructura.

Componentes desplegados

  • Apache: servidor web encargado de publicar la aplicación.
  • PHP: lenguaje utilizado para la lógica de la aplicación.
  • MySQL: sistema gestor de base de datos.
  • phpMyAdmin: herramienta web para administrar la base de datos durante el desarrollo.

Arquitectura lógica

Usuario / Navegador
        │
        ▼
Servidor Apache + PHP
        │
        ▼
Base de datos MySQL
        │
        ▼
Administración mediante phpMyAdmin

Qué demuestra este despliegue

  • Instalación y configuración básica de servicios Linux.
  • Despliegue de una aplicación web.
  • Integración entre servidor web y base de datos.
  • Administración de MySQL mediante phpMyAdmin.
  • Documentación de servicios dentro de una infraestructura.

Consideraciones de seguridad

En un entorno real, phpMyAdmin no debería quedar expuesto públicamente sin controles adicionales. Es recomendable restringir acceso, usar credenciales fuertes, HTTPS y reglas de firewall.

  • Restringir acceso a paneles de administración.
  • Usar contraseñas robustas.
  • Separar servicios críticos por red o contenedor.
  • Aplicar actualizaciones de seguridad.
  • No publicar credenciales ni configuraciones sensibles.

Conclusión

Este despliegue sirve como base para entender cómo se conectan los servicios clásicos de una aplicación web y cómo documentarlos dentro de un proyecto de infraestructura IT.
