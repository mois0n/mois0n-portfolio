Automatización de alertas de stock mediante Python

En esta entrada documento una parte del proyecto de infraestructura en la que se utiliza Python para consultar una base de datos MySQL y detectar productos con bajo stock.

Python MySQL Automatización Linux Infraestructura IT

Objetivo

El objetivo de esta automatización es demostrar cómo un script puede integrarse con una base de datos para revisar información de forma periódica y generar avisos cuando se cumpla una condición concreta.

Contexto del proyecto

Dentro de la infraestructura se desplegó una aplicación web conectada a una base de datos MySQL. Esta base de datos almacena productos y unidades disponibles.

Para añadir una capa de automatización, se planteó un script que consulta los productos y detecta aquellos cuyo stock baja de un umbral definido.

Ejemplo de lógica

# Ejemplo simplificado de lógica

umbral_stock = 5

for producto in productos:
    if producto["stock"] < umbral_stock:
        print("Producto con bajo stock:", producto["nombre"])

En un entorno real, este aviso podría enviarse por correo, Telegram, sistema de tickets o integrarse con herramientas de monitorización.

Buenas prácticas

  • No guardar credenciales directamente en el código.
  • Separar configuración y lógica del script.
  • Registrar errores y resultados.
  • Ejecutar el script con permisos mínimos.
  • Documentar el funcionamiento y las dependencias.

Conclusión

Esta automatización demuestra cómo una necesidad sencilla puede resolverse mediante scripting, conectando servicios desplegados dentro de una infraestructura y aportando valor práctico a la administración del entorno.
